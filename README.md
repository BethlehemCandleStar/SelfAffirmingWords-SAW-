# Self Affirming Words (SAW)

A functioning front-end prototype for DSO201 Design Studio 3 Assessment 2.

## Included
- Public-facing SAW website
- Login / sign-in prototype
- Daily SAW Agent affirmation generator
- User-created affirmations
- Personal reasons and image uploads
- Visual reminder
- Pause mode
- Profile and preferences
- Local browser persistence via `localStorage`
- Responsive layout
- Design credit and date

## Assessment framing
Figma was used for wireframing and interface development. This web app is the functional prototype used for testing and evaluation.

## Important
This is a front-end assessment prototype. Email/password sign-in is simulated locally and is **not** production authentication. The SAW Agent produces personalised daily text from local templates using the user's saved focus, tone and reasons.

SAW is presented as a motivational wellbeing tool, not medical treatment, addiction treatment, emergency support or a substitute for professional care.
